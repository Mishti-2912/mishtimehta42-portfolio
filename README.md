# B.Tech student portfolio

Plain HTML, CSS and JavaScript. No build step.

## Add your details
1. Put your photo in this folder as `photo.jpg` (portrait, about 800 x 1000 px). Until then, your initials show.
2. Put your resume in this folder as `resume.pdf`.
3. Replace "Your Name", college, CGPA and skills in `index.html`.
4. Edit the `projects` list and `EMAIL` in `script.js`.

## Publish
Push to GitHub, then Settings > Pages > `main` branch, root folder.
